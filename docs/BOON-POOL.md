# Boon pool — the full list (VEX 3.5/10)

The tester asked for the full boon pool to be listed so build variety can be
checked. This is that list, copied from `scripts/boons.gd` — if a boon is
added or changed there, update this file to match. Pick 1 of 3 on level-up.

## Common boons

| Boon | Effect |
| --- | --- |
| Heavy Hammer | +25% hammer damage |
| Sharpened Edge | +25% hammer damage, faster swing |
| Twin Axes | +1 throwing axe, −8% axe cooldown |
| Wide Nova | +30% rune nova radius |
| Swift Feet | +12% move speed |
| Thick Hide | +20 max HP, heal 20 |
| Shard Magnet | +50% shard pickup radius |

## Rare boons

| Boon | Effect |
| --- | --- |

| Oathbound | +25 max HP, heal 25 |

## Evolutions (gated — only offered once the prerequisite boon was taken)

| Evolution | Effect | Needs |
| --- | --- | --- |
| Stormcaller | Nova strikes twice | nova lvl 3 + Chain Lightning |
| Ashen Berserker | Hammer hits splash | hammer lvl 3 + Rage on Kill |
| Skald's Hail | Axes rain from the sky | axes lvl 3 + Shard Magnet |
| Sunstone Herald | Hammer and nova strike together | Stormcaller |

## Carry combos — the builds meant to carry Acts 2–3

- **Stormcaller** — maxed rune nova + Chain Lightning: clears Act 2 draugr packs.
- **Ashen Berserker** — maxed hammer + Rage on Kill: duels the Act 3 boss up close.
- **Skald's Hail** — maxed throwing axes + Shard Magnet: keeps XP flowing in Act 3.
- **Sunstone Herald** — Stormcaller + Sunstone Herald: the Act 3 boss-killer combo.

Total: **19 boons** (7 common, 8 rare, 4 evolutions) across the 3 weapons
plus movement, survival, and pickup stats — so Acts 2–3 have real build
variety instead of three weapons with the same few picks.
